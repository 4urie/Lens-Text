# Contributing to Lens Text

Thanks for your interest in improving Lens Text. Bug reports, documentation updates, and focused code contributions are welcome.

## Before you start

- Check existing issues and pull requests to avoid duplicating work.
- For a significant change, open an issue first to discuss the approach.
- Keep changes focused and describe the user problem they solve.

## Set up the project

1. Install a current version of Node.js and npm.
2. Clone the repository and open a terminal in its folder.
3. Install dependencies with `npm install`.
4. Start the web app with `npm run dev` or the desktop development app with `npm run dev:desktop`.

## Make and submit a change

1. Create a branch for your change.
2. Make the change and describe any user-visible behavior in your pull request.
3. Run `npm run lint` and `npm run build` before opening the pull request.
4. Open a pull request against `main`, summarize what changed, and include steps to verify it. Add screenshots for visual changes when practical.

Please do not include secrets, personal data, generated installers, or large build artifacts in a pull request. The project uses the MIT License; contributions are submitted under that license.

## Reporting a security issue

Please do not post exploitable security details in a public issue. Contact the repository owner privately through GitHub so the issue can be reviewed before public disclosure.
